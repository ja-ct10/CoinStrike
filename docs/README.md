# CoinStrike - Web Version

Play CoinStrike directly in your browser!

## How to Play

Visit the game at: `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`

### Controls

- **W/A/D or Arrow Keys** - Move
- **SPACE or W** - Jump
- **F** - Fire gun (35 bullets)
- **T** - Throw spear (10) / grenade (15)
- **B** - Open/close shop
- **ENTER** - Select/confirm in menus

### Gameplay

- Collect coins to buy weapons from the shop
- Kill enemies to build combo multipliers
- Complete 3 missions to face the final boss
- Avoid falling into pits and watch out for glitch platforms!

## Technical Details

This web version is built with:

- **Pygbag** - Python to WebAssembly compiler
- **Pygame** - Game framework
- **GitHub Pages** - Hosting

## Note

The game runs entirely in your browser using WebAssembly. No installation required!
